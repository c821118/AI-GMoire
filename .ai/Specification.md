## 1. 專案背景與目標

**AI-GMoire**（原名 GM-Prompt-Toolkit）是一套專門設計給 AI 閱讀的 TRPG（桌上角色扮演遊戲）規則書，讓 AI 能夠扮演遊戲主持人（GM）。
專案包含兩大核心分支：
1. **霍格華茲專用版**：以《哈利波特》及《霍格華茲的傳承》為世界觀（目前已停止研發，但運作穩定）。
2. **通用版**：基於霍格華茲版提煉出的輕量化、低 token 消耗的通用核心引擎。

本專案旨在將現有的 Markdown 規則文件，轉換為適用於各種 AI 平台（如 Antigravity, Chub.ai, SillyTavern）的標準格式。

## 架構設計

### 雙層架構

```
┌─────────────────────────────────────────────┐
│           通用 TRPG 規則（引擎層）             │
│  ┌──────────────────┐  ┌──────────────────┐  │
│  │  AI TRPG 主規則   │  │  PC 角色卡        │  │
│  │  (每回合必讀)     │  │  (僅第 1 回合)    │  │
│  └──────────────────┘  └──────────────────┘  │
├─────────────────────────────────────────────┤
│           主題 Lorebook（內容層）              │
│  ┌──────────────────────────────────────┐    │
│  │  霍格華茲 1991 / 霍格華茲 1890 / ...  │    │
│  │  (按關鍵字觸發，按需注入)              │    │
│  └──────────────────────────────────────┘    │
└─────────────────────────────────────────────┘
```

- **引擎層（主規則）**：定義 GM 行為準則、權限級聯、進度總結格式、輸出格式。每回合都會被 AI 讀取。
- **內容層（Lorebook）**：定義特定世界觀的資料，包含 NPC、魔法體系、地理、課表等。以關鍵字觸發方式按需注入，節省 token。
- **PC 角色卡**：定義遊戲細節（主題、角色設定、風格、週期）。僅在第 1 回合讀取，後續依賴「進度總結」延續。

### Token 運作流程

```
第 1 回合：主規則 + PC角色卡 + Lorebook(觸發部分) → AI 生成開局
第 2 回合：主規則 + 對話上下文 + Lorebook(觸發部分) → AI 繼續敘事
  ...
第 N 回合：主規則 + 對話上下文 + Lorebook(觸發部分) + 進度總結 → AI 繼續敘事
```

## 輸出格式

霍格華茲規則應產出三種格式：

### 1. Antigravity Skill

- 格式：YAML frontmatter + Markdown（`SKILL.md` + `references/` 子資料夾）
- 用途：供 Antigravity 及其他支援相同結構的 AI 平台讀取
- 相容性：任何接受 YAML frontmatter + Markdown 的 AI 平台

### 2. chub.ai Character Card（獨立運行）

- 格式：`chara_card_v2` JSON，V3 兼容
- 用途：在 SillyTavern 中作為獨立 GM 角色使用
- 架構：
  - `system_prompt` → 主規則（核心引擎）
  - `description` → GM 角色定義
  - `first_mes` / `alternate_greetings` → 開局路線
  - `post_history_instructions` → 輸出格式與進度總結指令
  - `character_book` → 內嵌 Lorebook（檢索資料庫拆分為條目）

### 3. Lorebook（搭配通用規則使用）

- 格式：SillyTavern Lorebook JSON（`character_book` 結構）
- 用途：搭配通用版 TRPG 主規則使用，作為「主題包」
- 內容：將「主規則 + 檢索資料庫 + 開局角卡」整合為一個 Lorebook
- 版本：1991 與 1890 各一份

## 設計原則

### 通用版規則

| 原則 | 說明 |
|---|---|
| **輕量至上** | 整份通用規則（主規則 + PC 角色卡）禁止超過 1,500 token |
| **主規則精簡** | 主規則目標控制在 800 token 以內 |
| **引擎與內容分離** | 主規則不包含任何特定主題的世界觀資料 |
| **角色卡即設定** | 遊戲細節由 PC 角色卡規範，而非主規則 |
| **進度總結接力** | PC 角色卡僅第 1 回合使用，後續靠進度總結延續細節 |

### 霍格華茲規則

| 原則 | 說明 |
|---|---|
| **唯讀原始檔** | 原始 `.md` 檔案不修改，所有產出為新增檔案 |
| **皇冠版翻譯** | 所有中文名詞以台灣皇冠出版社繁體中文翻譯為準 |
| **已停止研發** | 僅進行格式轉換與 Bug 修正，不新增功能 |

### 跨格式原則

| 原則 | 說明 |
|---|---|
| **單一真相源** | Markdown 為真相源，其他格式（JSON、Card）由其衍生 |
| **Lorebook 按需觸發** | 世界觀資料以關鍵字觸發，避免每回合全量注入 |
| **版本標記** | 所有產出檔案標記版本號，便於追蹤變更 |
