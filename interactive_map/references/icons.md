# 圖示規格與圖示庫

地圖上每個地點都有一個線條圖示。引擎負責外圈與上色（依狀態：已到訪＝墨色實線外圈、今所在＝紅底反白、耳聞＝淡色虛線、擬往＝金色虛線），所以**圖示本身只畫形狀，不指定顏色**。圖示風格參考 [Tabler Icons](https://tabler.io/icons)（MIT）：24×24 格、等粗線條、圓角圓端。

## 使用方式

1. 在下方圖示庫找到需要的種類，把它的片段複製到資料區塊的 `icons`，key 就是種類名：`village:'<path d="..."/>',`
2. 地點的 `t` 填同一個種類名。**`icons` 只放這張圖用到的**（省額度）；之後新增地點種類，就在 `icons` 加一行。
3. `t` 沒有對應圖示時，引擎會畫成通用圓點；請告訴玩家這是通用標記，或依下面規格自繪一個。
4. 片段是單引號字串，內部一律用雙引號，不要換行。

## 規格（自繪與擴充時必須遵守）

| 項目 | 規定 |
|---|---|
| 畫布 | 24×24，內容限制在 2～22 之內，四邊留白 |
| 線條 | 只畫線，**不填色**；不寫 `fill`、`stroke`、`stroke-width`、`class`、`style`（引擎統一設定：約 1.6px、圓端點、圓轉角） |
| 元素 | 只用 `path` `circle` `ellipse` `rect` `line` `polyline` `polygon`。不用 `text`、`image`、`use`、漸層、濾鏡、`transform` |
| 簡潔 | 一個圖示一個概念，至多 5 個元素；顯示尺寸只有約 16px，**細節會糊掉**：平行線與間隙至少 2 個單位，不畫小於 2 單位的細節 |
| 筆法 | 轉角用圓弧（半徑 1～2）；角度以 90°、45° 為主；座標盡量取整數或 .5 |
| 辨識 | 一眼就能從輪廓認出；與圖示庫裡相近的圖示要有明顯差異（例如村莊的單棟屋頂 vs 小鎮的多棟建築） |
| 命名 | 種類名用英文小寫（`hotspring` 這類連寫）；不可用已存在的名稱表示不同圖形 |

**不要憑記憶默寫 Tabler 的路徑。** 路徑細節記錯就會變成怪形狀。圖示庫裡有的直接複製；沒有的，自己依上面的規格畫，並告訴玩家這是自繪圖示。

自繪的方式：先想 2～3 個最能代表它的特徵（水井＝井口橢圓＋井壁＋支架＋頂篷），再用最少的線畫出來。
