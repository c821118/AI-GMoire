# 互動地圖 Skill

為玩家畫出「目前進度」的互動式地圖。你（GM）寫的是**資料**，繪製與互動由 `references/map-template.html` 內固定的程式負責。

## 原則（不可違反）

1. **地圖是給玩家看的，不是給 GM 看的。** 不得以地圖作為遊戲準則、不得靠它推演劇情或距離；與劇情紀錄衝突時，以劇情為準。
2. **更新須經玩家同意**（避免耗盡 agent 額度）。不要每回合都問；在自然斷點（抵達新地點、揭曉一片新區域、章回結束）簡短問一句「要更新地圖嗎？」，玩家同意才動手。玩家主動要求則直接做。
3. **不捏造。** 路徑、地點、地形、名稱，都必須是你與玩家的對話中**已經出現**的。沒發生的不畫，不為了「好看」補完。未探索＝未知，只畫已知。
4. **GM 的秘密不得進入地圖。** 玩家看得到原始碼，所以資料與註解裡都不能有尚未被玩家發現的事（隱藏地點、敵人身分、劇情走向）。
5. **單一 HTML 檔**：不另外產生 js／css 檔；**不含任何圖像、不生成圖像**，一律用 HTML／CSS／JS／SVG 繪製（玩家主動提供的圖片除外）；不連外部資源、不使用 localStorage／cookie。
6. **只做地圖。** 不加裝備、人物、任務等版面。版面精簡、可收闔、以點擊為主不靠 hover（模板已做好，不要改）。

## 初次建立

1. **先問清楚（一次問完，別追問太多輪）**：
   - 地圖大概涵蓋多大？起點在哪？有沒有可用的比例（例如「步行一天」「約 30 公里」）？沒有就用示意圖，不畫比例尺。
   - 玩家有沒有**風格參考**（文字描述、配色、圖片）？有就照「風格與素材」處理；沒有就用預設的古地圖風格。
2. **盤點已揭曉的內容**：從對話整理出：去過的地點、走過的路線與階段、親眼見到的地形（河、山、森林、湖、邊界）、聽說但沒去過的地方、玩家說過打算去的地方。不確定的，問玩家，不要猜。
3. **讀 `references/map-template.html`，完整輸出整份 HTML。** 只允許改 `DATA-START` 到 `DATA-END` 之間的 `MAP`；其餘（CSS、引擎）**逐字照抄**，不要簡化、不要重寫。範例資料（霧原谷地）**必須全部換掉**，不得殘留。需要地點圖示時，再讀 `references/icons.md`，只把這張圖用到的圖示複製進 `icons`。
4. **輸出方式**：能預覽 HTML 的介面（Claude artifact、ChatGPT canvas、Gemini Canvas）→ 建立成 HTML 檔或畫布；否則輸出一個完整的 HTML 程式碼區塊，請玩家存成 `.html` 後用瀏覽器開啟。
5. **交付時用一兩句話告訴玩家**：操作方式（拖曳、雙指縮放、點地點看說明、上方標籤依階段檢視）、這是示意圖（方位距離為約略）、哪些圖示是自繪的或通用標記。

## 更新（玩家同意後）

- 更新＝**對現有檔案做局部修改**，只動 `MAP` 資料區塊，只新增或修改這次揭曉的項目。新項目加在各陣列最後面。
- 介面不支援局部修改時，才重新輸出整份，並說明原因。
- 已揭曉的內容不得無故刪除；劇情上確實改變時才改（橋被炸毀 → 改 `d` 說明或加註記）。
- 同步更新 `meta.sub`（目前所在）、`s:"c"` 的地點（舊的 `c` 改成 `v`）。
- 更新後只說這次新增了什麼，不要重述整份資料。

## 資料格式

座標：`x` 向右、`y` 向下，單位為**世界座標**，全圖寬約 900～1200 為宜。用劇情中給過的方位、距離、行進時間推算；資訊不足時用保守間距，並讓玩家知道這是示意。`meta.bounds` 設為**已知範圍加一點邊距**，不是整個世界。

### `meta`
`title`、`sub`（階段・時間・所在，一行）、`seal`（1～2 字）、`bounds:[x0,y0,x1,y1]`、`viewPhone`（選填，手機初始視野）、`scale:{n,u,len}`（`n` 個 `u` 單位 = `len` 世界座標，省略則不畫比例尺與方格）、`grid`、`seed`（**建立後不要改**，樹與山的位置靠它固定）、`reveal`（迷霧揭開範圍倍率，預設 1）、`legend`（圖例文字）、`note`、`seen`（遠望範圍，見下）。

### `chapters`（階段）
`{id,s,n,t,w}`：`s` 簡稱（籤上顯示）、`n` 名稱、`t` 標題、`w` 時間。`plan:true` 是「下一步」。`f:[x0,y0,x1,y1]` 與 `min` 可指定該階段的視野。路線與地點用 `ch` 指向它。只有一個階段時可寫成空陣列（不顯示籤）。

### `terrain`（地形，只寫親眼看過的）

| `k` | 欄位 | 畫成 |
|---|---|---|
| `river` | `id`、`pts`、`w` | 河流（`id` 供路線沿河用；只寫看過的河段） |
| `sea`、`water` | `pts`（封閉輪廓） | 海、湖 |
| `marsh` | `cx,cy,rx,ry,rot` | 沼澤 |
| `forest`、`hills`、`desert` | `pts`（多邊形範圍）、`step` | 範圍內自動散布樹、丘、沙丘 |
| `ridge` | `a`、`b`、`s` | 沿線段排列山峰 |
| `line` | `cls`:`boundary`/`wall`/`road`/`coast`、`pts`、`closed` | 邊界、城牆、已知道路、海岸 |
| `path` | `d`、`cls` | **自由 SVG path**：用 `d` 直接畫輪廓（海岸、島、特殊地形） |

每個項目給唯一 `id`（隨機散布靠它固定；沒有 `id` 則依順序）。形狀要新創時，優先用 `path` 自由繪製，不要為了好畫而改引擎。

### `routes`（玩家走過的路）
`{ch,m,from,to,along|via}` 或 `{ch,m,pts}`：`m` 是 `solid` 實線／`dash` 虛線／`dot` 點線／`plan` 擬行（玩家或 NPC 明確表示打算走）。`from`、`to` 填地點 `id`；`along:"河id"` 沿河取路；`via:[[x,y]]` 加途經點；`pts` 可混用地點 `id` 與 `[x,y]`。**只記錄實際走過的段落**。圖例文字用 `meta.legend` 為 `solid/dash/dot/plan` 命名（例如水路、陸路）。

### `places`（地點）
`{id,n,x,y,s,t,ch,pos,now,d}`

- `s`：`c` 現在所在（同時只能有一個）／`v` 已到訪／`h` 耳聞未至／`p` 擬往。
- `t`（圖示種類）：必須是 `icons` 裡有的名稱，例如 `village` `town` `city` `inn` `mine` `cave` `hotspring`（完整清單與片段見 `references/icons.md`）；`edge` 是圖外的遠方，只有文字，名稱可加箭頭如「↑ 王都」，狀態用 `h`。
- `pos`：標籤位置 `l r t b`；`now`：一句話說明位置；`d`：玩家點開看到的說明（只寫玩家已知的事）。
- 縮放控制（選填）：`minK` 低於此縮放只顯示圓點不顯示名稱；`showK` 低於此完全隱藏；`hideAbove` 高於此隱藏（城市放大後換成城內地點時用）；`r` 單點揭開半徑。
- `t` 沒有對應圖示時會畫成通用圓點（console 會警告）。請告訴玩家這是通用標記，或自繪一個。

### `icons`
`{種類名:'<svg 片段>'}`：只放這張圖用到的圖示，片段從 `references/icons.md` 複製；新增地點種類時加一行（局部更新就是改這裡）。

### `labels`
`{t,x,y,cls,rot,minK,maxK,ch}`：`cls` 為 `riverl`／`mtnl`／`geo`／`region`／`fogl`（「未詳」）。

### `seen`（`meta.seen`）
`[{x,y,r}]`：遠望到但沒去過的範圍（山脈輪廓、對岸森林）。迷霧在這裡揭開得較淡。

## 揭曉與不捏造

- 迷霧**只依據已列出的地點、路線、`seen` 揭開**；沒列出的區域一律是迷霧。
- 迷霧**只遮地形與底色，不遮文字與標記**。所以 `labels`、`places` 只能寫已揭曉的名稱；不要把還沒到過的地點先放上去。

| 情況 | 怎麼寫 |
|---|---|
| 玩家到過、親眼見過 | `s:"v"`，路線、地形照實畫 |
| 只從遠處看見輪廓 | 地形寫進 `terrain`，並用 `seen` 揭開那一小片 |
| 傳聞、NPC 口述、地圖上聽說 | `s:"h"` 或 `t:"edge"`，`d` 註明是傳聞；**不畫成已知地形** |
| 玩家說打算去 | `s:"p"` 與 `m:"plan"`（要有人明確說過） |
| 劇情沒提過的細節 | 不畫。用最保守的描述，寧缺勿濫 |

## 風格與素材

- **風格參考**：玩家給文字或圖片描述時，用 `meta.theme`（淺色）與 `meta.themeDark`（深色）覆寫配色變數：`fog land ink ink-soft water mount route plan panel line halo`（可寫成 `{route:"#8a3b2c"}`），字體用 `font-display`、`font-body`（只用系統字體堆疊）；也可調 `seal`、圖例用語。**不要改版面與互動**。要求超出模板能力（方格地圖、室內平面圖）時，說明目前只支援自由繪製的地圖，詢問是否仍要繼續。
- **玩家提供底圖**：才可使用圖片。只能引用玩家給的網址或與 HTML 同資料夾的檔名（`meta.base:{href,x,y,w,h,o}`），底圖同樣被迷霧遮住。不得自己生成或內嵌圖片。
- **圖示**：一律用 `references/icons.md` 的圖示庫與規格（24×24 線條圖示，風格參考 Tabler Icons，MIT）。庫裡沒有的種類，依該檔規格**自己畫**，並告訴玩家是自繪圖示；**不要憑記憶默寫 Tabler 的路徑**。不要混入其他風格的圖示庫；game-icons.net（CC BY 3.0）等風格不同，除非玩家明確要求，否則不用。HTML 開頭的 Tabler 授權註解必須保留。

- [ ] 資料與註解裡有沒有 GM 秘密、劇透？
- [ ] 範例資料（霧原谷地、示範說明）全部換掉了？
- [ ] 路線的 `from`／`to`／`along` 引用的 `id` 都存在？`id` 沒有重複？只有一個 `s:"c"`？
- [ ] 傳聞與擬往沒有被畫成已知地形？
- [ ] 每個地點的 `t` 在 `icons` 裡都有對應圖示（或已告知玩家用通用圓點）？圖示片段是複製或依規格自繪，沒有憑記憶默寫？
- [ ] 沒有圖像、沒有外部連結、沒有改動引擎程式？
