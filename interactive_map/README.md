# interactive_map（RPG 互動地圖）

給玩家看的 TRPG 互動地圖。把整個 `interactive_map/`（skill）提供給 AI-RPG 的 GM 閱讀，GM 就能依目前進度輸出一個**單檔 HTML** 地圖：自由 SVG 路徑繪製、RWD、可縮放拖曳、點地點看說明、依章回篩選路線；只畫已揭曉的內容，未探索的區域以迷霧遮住。可獨立使用，也可搭配本專案的任何 GM Skill。

```
interactive_map/
├── SKILL.md                      ← 規範：原則、流程、資料格式、不捏造規則
├── references/map-template.html  ← 固定的繪製引擎 + 一段資料區塊（GM 只改資料）
└── references/icons.md           ← 圖示風格規格 + 66 個地點圖示庫（Tabler 風格線條圖示）
```

## 設計重點
- **GM 寫資料，引擎負責繪製**：地形、路線、地點都是 `MAP` 資料；樹與山的位置由固定種子產生，同一份資料永遠畫出同一張圖。更新時只局部修改資料。
- **不捏造**：迷霧只依已列出的地點、路線與遠望範圍揭開；傳聞、擬往與已到訪分開標示。
- **更新須玩家同意**，以節省 agent 額度。
- 無圖像、無外部資源、無瀏覽器儲存；配色支援淺色／深色，玩家可提供風格參考。
- **圖示**：24×24 線條圖示（風格與部分圖形取自 Tabler Icons，MIT，授權文字已寫在模板開頭註解；其餘自繪），引擎依狀態畫外圈與上色。GM 只把用到的圖示複製進資料區塊的 `icons`；庫裡沒有的，依 `icons.md` 的規格自繪擴充。
- 範本來源：`.ref/map-ref/琥珀行跡圖.html`（外觀與互動沿用，去掉故事專屬程式與外部字型）。
